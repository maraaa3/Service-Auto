# Service-Auto

## Description
Service-Auto is an automotive service management system built using Object-Oriented Programming (OOP) principles. It provides a robust platform for managing vehicle services, appointments, and maintenance records.

## Purpose
The primary purpose of this project is to streamline automotive service operations by providing an efficient system for:
- Managing customer vehicles
- Scheduling service appointments
- Tracking maintenance history
- Managing service records and invoicing

## Technology Stack
- **Language:** Java with OOP principles
- **Architecture:** Object-Oriented Design

## Key Features
- **Customer Management:** Register and manage customer information
- **Vehicle Management:** Keep track of vehicles and their specifications
- **Service Scheduling:** Book and manage service appointments
- **Maintenance History:** Maintain detailed records of all services performed
- **Service Records:** Track parts used, labor hours, and costs
- **Invoice Generation:** Automatic invoice creation for completed services

## Project Structure
The project follows OOP principles with:
- **Classes:** Well-defined entities representing customers, vehicles, services, and appointments
- **Encapsulation:** Data hiding and controlled access through methods
- **Inheritance:** Code reuse through class hierarchies
- **Polymorphism:** Flexible behavior through method overriding

## How to Use
1. Clone the repository
2. Set up the Java development environment
3. Compile the project
4. Run the application
5. Follow the on-screen instructions to manage services

## Main Components
- **Customer Module:** Handle customer data and contact information
- **Vehicle Module:** Manage vehicle details and service history
- **Service Module:** Track available services and pricing
- **Appointment Module:** Schedule and manage appointments
- **Invoice Module:** Generate and manage service invoices
